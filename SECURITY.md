# Security Policy

Workflow Studio launches local Codex workers and permits either one exact output-file write or writes inside an explicit bounded set of repository paths. Security reports involving path validation, writes outside the requested scopes, Git metadata mutation, sandbox escape, unintended network access, arbitrary execution, credential exposure, or misleading acceptance should not be filed as public issues.

After the GitHub repository is published, use GitHub private vulnerability reporting. Until then, contact the repository owner privately before sharing exploit details.

Supported release line: `0.2.x`.
